## Project Overview

This project implements the **Knowledge Discovery in Databases (KDD)** process to analyze the "Significant Volcanic Eruption Database" from the National Center for Environmental Information (NCEI). The dataset covers over 600 eruptions dating back to 4360 BC.

The analysis focuses on understanding volcanic risks, historical impacts, and identifying patterns in volcanic activity through data cleaning, exploration, and an advanced interactive dashboard.

## Dataset

*   **Source**: National Center for Environmental Information (NCEI)
*   **Content**: "Significant Volcanic Eruption Database"
*   **Key Attributes**: Location, Time (Year/Mo/Dy), VEI (Volcanic Explosivity Index), Deaths, Injuries, Damage ($Millions), and Agent of Harm (e.g., Tephra, Tsunami).

## Project Structure

The project is contained within a single Jupyter Notebook (`CHAUVIGNE_VolcanicEruptions.ipynb`) which guides the user through the entire KDD pipeline:

### 1. Data Collection & Preprocessing
*   **Loading**: Import data from `volcano-events.tsv`.
*   **Cleaning**: 
    *   Handling missing values and "artefact" rows.
    *   Parsing dates (handling negative years/B.C.).
    *   Standardizing columns (Normal vs. Total metrics).
*   **Imputation**: Using description columns (ordinal scales) to impute missing numerical data.

### 2. Exploratory Data Analysis (EDA)
*   **Structure**: Examining data types and shapes.
*   **Rankings**: Identifying top deadliest and most destructive events.
*   **Consistency Checks**: Validating relationships between Tsunamis, Earthquakes, and Volcanic events.

### 3. Interactive Dashboard
The core deliverable is a comprehensive **Dash** application embedded in the notebook. It features a narrative-driven layout with interactive exploration capabilities.

**Key Components:**
*   **Narrative Sections**:
    *   *The Pareto Principle*: Highlighting that a small fraction of eruptions cause the majority of deaths.
    *   *The Matrix of Threat*: analyzing probability vs. impact (Stratovolcanoes vs. Calderas).
    *   *The Indirect Killer*: Revealing the lethality of secondary hazards like Pyroclastic flows and Tsunamis.
*   **Interactive Controls**:
    *   Global Filters: Country, Year Range, Region.
    *   Map Modes: Distribution, Frequency, Deaths, Damage.
*   **Detailed Exploration Tabs**:
    *   **Global Impact**: Top countries, VEI analysis, and Volcano Type statistics.
    *   **Regional Analysis**: Sunburst charts and Treemaps showing regional hierarchies of fatalities.
    *   **Injury Analysis**: Scatter and Bubble charts comparing deaths vs. injuries.
    *   **Distributions & Risk**: Boxplots and Correlation Heatmaps (Deaths, Damage, VEI).

## Technologies Used

*   **Python**: Core language.
*   **Pandas & NumPy**: Data manipulation and analysis.
*   **Plotly & Dash**: Interactive visualizations and dashboard framework.
*   **Prophet**: Time-series forecasting for volcanic events.
*   **Seaborn & Matplotlib**: Static visualizations for initial exploration.

## How to Run

1.  **Prerequisites**: Ensure you have the required libraries installed.
    ```bash
    pip install pandas numpy matplotlib seaborn plotly dash prophet
    ```
2.  **Data Placement**: Place the `volcano-events.tsv` file in the same directory as the notebook.
3.  **Execution**:
    *   Open `CHAUVIGNE_VolcanicEruptions.ipynb` in Jupyter Notebook or JupyterLab.
    *   Run all cells sequentially.
    *   The final cell launches the Dash app. Depending on your environment, it will run inline or provide a link to open in your browser (usually `http://127.0.0.1:8050/`).
